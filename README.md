# Multifractal Spatial Mapping

**An R workflow for geospatial attribution and interpolation of FracLac-derived descriptors from segmented satellite images.**

Development snapshot **v0.1.0-dev** — *not yet independently validated against the published article data*.

## What is this project?

This repository documents and modularizes the scientific workflow used to spatialize multi­fractal descriptors from segmented satellite imagery of floating *Sargassum* aggregations. Spectra are obtained in **FracLac / ImageJ** (external software), **not** calculated in this repository. The subsequent R workflow assigns section identifiers to spectral records, extracts per-partition descriptors, links them with georeferenced section centroids, fits semivariogram models and generates ordinary-kriging surfaces and variance rasters. Optional functionality produces morphological matrices and clusters.

**Pipeline:** georeferenced segmentation → image partitioning + centroid manifest → external FracLac → cleaned numeric spectral export → partition indexing → descriptor extraction → spatial join → semivariogram → ordinary kriging → maps and morphological matrices.

## Requirements

R 4.2+ recommended. For the full workflow install:

```r
install.packages(c('terra', 'sf', 'gstat', 'sp'))
```

Data-processing unit tests use only base R (`sf` adds spatial-join tests when installed). Additional system libraries may be required for sf/terra on Linux.

## Input contract

The original workflow processed a cleaned spectrum with **219 numeric rows per section** after excluding textual/metadata records from the FracLac export. This number is *specific to that output* and may not match other FracLac configurations. The cleaning of textual records is an **explicit upstream step**, not automatically inferred here.

Required files:

| File | Expected fields | Notes |
| --- | --- | --- |
| Cleaned FracLac spectra (CSV2, `;`) | `q`, `a`, `f.a.`, `d.q.` | Must be ordered in contiguous blocks per partition. No `partition` column yet. |
| Partition-order file (CSV2) | `partition` | In **exact FracLac processing order**, one row per processed tile. Do not assume that all saved tiles were analyzed. |
| Centroid manifest (CSV2) | `partition`, `centroid_x`, `centroid_y`, `crs`, `salvo` | Generated by R partitioning or equivalent. CRS MUST be known. |
| Region boundary | GeoPackage/shapefile | Must have declared CRS. |

**Warning:** indexing by repeated numbers cannot independently prove the *order* of FracLac's export. Preserve the image-to-result log and manually verify selected partitions. The 219-row convention cannot be applied to an uncleaned 220-row export.

## Quick start with synthetic data

Generate an example to understand the input contract (5 q records per section; no satellite/FracLac observations):

```bash
Rscript examples/make_example.R
Rscript scripts/run_workflow.R \
  examples/input/cleaned_spectra.csv \
  examples/input/partition_order.csv \
  examples/input/centroids.csv \
  examples/input/boundary.gpkg \
  examples/output 5
```

**Example images are synthetic**; the example verifies file interfaces and does not validate the scientific performance of kriging on real data. The kriging function requires at least 10 spatial points with nonconstant descriptor values; some toy datasets might yield no valid semivariogram fit, which must be diagnosed rather than hidden.

For the real 219-line cleaned spectrum, omit final `5`, or explicitly pass `219`.

Execute base-R tests:

```bash
Rscript tests/run_tests.R
```

## R modules

- `R/01_image_partitioning.R` — numbered tiles and centroid manifest; handles nodata and optional binary masks.
- `R/02_fraclac_spectrum_indexing.R` — replicate IDs for cleaned numeric spectral blocks; validate q sequence.
- `R/03_multifractal_descriptors.R` — Δα, signed Δf(α), α₀, D₀/D₁/D₂ and asymmetry ratio r.
- `R/04_spatial_attribution.R` — one-to-one join by partition and CRS-aware coordinates.
- `R/05_variogram_modeling.R` — candidate isotropic variograms and selection diagnostics.
- `R/06_ordinary_kriging.R` — ordinary kriging, output maps and model variance.
- `R/07_morphological_matrices.R` — extract co-registered raster values with coordinates.
- `R/08_cluster_analysis.R` — optional descriptive Ward.D2 grouping.

## Reproduction vs enhancements

The original combined script is preserved as `legacy/Metotologia_tese_original.R`. Some safeguards and defaults have changed; see [`docs/CHANGELOG_FROM_ORIGINAL.md`](docs/CHANGELOG_FROM_ORIGINAL.md). In particular, the article's script selected semivariograms with `SSErr`, whereas the modular code defaults to `RMSE_CV`. Set `criterion = 'SSErr'` for historical-method matching.

The code has not been used to regenerate the manuscript's numerical results in this environment. Report source attribution, FracLac/ImageJ version, data-cleaning decisions, masking, variogram-selection settings, and interpolation support in the paper. The final source repository/license and author list should be approved before an archival release.
